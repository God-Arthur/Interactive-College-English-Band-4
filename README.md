# Book III 期末复习答题系统

《大学英语（第三册）》期末考试题型模拟练习网站，覆盖 Unit 1-8 全部词汇。

## 快速开始

```bash
cd Interactive-College-English-Band-4
python -m http.server 8080
```

浏览器打开 http://localhost:8080/ 即可使用。

## 练习模块

首页提供 7 个练习入口：

| 模块 | 题型 | 题数 | 说明 |
|------|------|------|------|

## 功能特性

- **答题判分**：提交后即时显示对错、正确答案和中文解析
- **进度跟踪**：进度条按当前题号前进，并实时显示得分
- **上一题/下一题**：支持来回翻看，已答题目自动恢复状态
- **结束练习**：题库很长时可以提前交卷；未作答的题单独统计，不计入答错
- **错题重做**：练习结束后只重做答错的题，答案清空后重新作答
- **结果统计**：总分、已答、答对、答错、未答、正确率和分题型统计
- **填空兼容**：忽略大小写和多余空格；英美拼写、连字符写法和常见过去式变体都算对
- **键盘快捷键**：
  - `1-4` 选择 ABCD 选项
  - `Enter` 提交答案 / 进入下一题
  - `←` / `→` 上一题 / 下一题

## 题库数据来源

- 主词表：`大英四词表.txt`（Unit 1-8，含 ★ 重点词标注）
- 额外词：`额外词.txt`（课文中出现但不在主词表内的词）
- 易错词：`易错词.txt`（实际答题中答错的词）

## 出题原则

- **Part III**：四个选项全部来自词表，干扰项为形近词/同根词/近义但语境不符的词
- **Part V**：给出首字母和中文提示。一个空填一个词；短语有几个空就按顺序填几个词，中间用空格分开
- **多义词**：每个释义独立出题，优先考查次要/生僻义项
- **答案**：填进去之后句子要成立，该用复数、过去式或分词时就使用那个形式。大小写、英美拼写和连字符不影响判分
- **句子**：自造例句模块的句子全部原创，未沿用词表例句

## 技术栈

纯前端实现（HTML + CSS + JavaScript），无需后端，无需依赖，浏览器直接打开即可使用。
