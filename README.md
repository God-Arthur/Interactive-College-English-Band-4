# Book III 期末复习答题系统

《大学英语（第三册）》期末考试题型模拟练习网站，覆盖 Unit 1-8 全部词汇。

## 快速开始

```bash
cd Interactive-College-English-Band-4
python -m http.server 8080
```

浏览器打开 http://localhost:8080/ 即可使用。

## 练习模块

首页提供 6 个练习入口：

| 模块 | 题型 | 题数 | 说明 |
|------|------|------|------|
| Part III 练习 | 单选题 | 204 | 句子挖空，四选一，选项全部来自词表 |
| Part V（书本） | 填空题 | 200 | 基于词表例句改编，首字母+中文提示 |
| Part V（自造例句·全释义覆盖） | 填空题 | 574 | 自造例句，多义词每个释义独立出题 |
| Unit 8 专项练习 | 填空题 | 138 | Unit 8 全部词汇，自造例句，乱序 |
| 易错词专项练习 | 填空题 | 40 | 实际答题中答错的词，自造例句 |
| 额外词专项练习 | 填空题 | 102 | 课文中出现但不在主词表内的词 |
| **合计** | | **1258** | |

## 功能特性

- **答题判分**：提交后即时显示对错、正确答案、中文解析
- **进度跟踪**：实时进度条 + 得分显示
- **上一题/下一题**：支持来回翻看，已答题目自动恢复状态
- **错题回顾**：练习结束后可单独重刷错题
- **结果统计**：总分、正确率、分题型统计
- **键盘快捷键**：
  - `1-4` 选择 ABCD 选项
  - `Enter` 提交答案 / 进入下一题
  - `←` / `→` 上一题 / 下一题

## 题库数据来源

- 主词表：`大英四词表.txt`（Unit 1-8，含 ★ 重点词标注）
- 额外词：`额外词.txt`（课文中出现但不在主词表内的词）
- 易错词：`易错词.txt`（实际答题中答错的词）

## 出题原则

- **Part III**：四个选项全部来自词表，干扰项为形近词/同根词/近义但语境不符的词
- **Part V**：给出首字母 + 中文提示，填写完整单词
- **多义词**：每个释义独立出题，优先考查次要/生僻义项
- **答案**：全部使用词表原型，不要求词形变化
- **句子**：自造例句模块的句子全部原创，未沿用词表例句

## 技术栈

纯前端实现（HTML + CSS + JavaScript），无需后端，无需依赖，浏览器直接打开即可使用。
